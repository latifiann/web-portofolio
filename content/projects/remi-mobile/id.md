## Gambaran umum

ReMi adalah aplikasi tugas dan pengingat untuk mahasiswa, dikembangkan oleh tim beranggotakan delapan orang untuk mata kuliah Agile Product Based Learning pada 2024. Pengingat disampaikan melalui notifikasi dan alarm di ponsel. Tim bekerja melalui iterasi Agile dengan feature branch, pull request, dan perbaikan bug secara berkala.

ReMi Mobile dan ReMi Web merupakan dua deliverable terpisah. Studi kasus ini membahas aplikasi mobile dan bagian yang saya kerjakan. Repository mobile bersifat privat dan dimiliki tim, sehingga tidak ada tautan kode sumber yang dipublikasikan.

ReMi juga memiliki mekanisme hadiah berupa koin. Pengguna mendapatkan koin dengan menyelesaikan tugas, lalu menggunakannya untuk membeli aset di dalam aplikasi, seperti tema. Saat sesi review pengguna, beberapa pengguna menyampaikan bahwa hadiah tersebut membuat aplikasi lebih menarik dan mendorong mereka menyelesaikan tugas untuk mendapatkan koin.

## Tanggung jawab saya

- Berkontribusi pada fitur tugas berbasis BLoC, termasuk date picker, pembatalan optimistic delete, validasi input, serta penanganan kondisi loading dan error.
- Membangun dan menyempurnakan layar Flutter untuk profil, autentikasi, sambutan, dan alarm, termasuk integrasi animasi Lottie.
- Mengintegrasikan REST API dengan Dio dalam Clean Architecture berbasis fitur, termasuk alur lupa kata sandi.
- Mengimplementasikan UI gamifikasi, state management dengan BLoC, dan integrasi API, serta menyiapkan aset tema dengan warna yang disesuaikan untuk setiap tema.
- Mengikuti alur Agile tim dengan feature branch, pull request, dan iterasi perbaikan bug.
- Berpartisipasi dalam Design Sprint dan perancangan antarmuka di Figma sebelum implementasi.
- Menguji aplikasi secara manual selama pengembangan dan memperbaiki masalah yang ditemukan saat review. Studi kasus ini tidak mengklaim adanya automated test suite.
- Membuat video promosi ReMi dengan Adobe After Effects, dengan ide dan saran dari teman satu tim.
