## Gambaran umum

ReMi Web App adalah produk web untuk aplikasi tugas dan pengingat ReMi, dikembangkan untuk mata kuliah Agile Product Based Learning pada 2024. Produk ini merupakan deliverable terpisah dari ReMi Mobile, yang dipublikasikan di Google Play oleh tim beranggotakan delapan orang yang sama.

Produk web dibangun dengan React, TypeScript, Vite, dan Tailwind CSS, serta menggunakan REST API tim untuk autentikasi, tugas, filter tenggat, dan pengingat. Tim juga merencanakan tampilan Eisenhower Matrix, area profil, gamifikasi misi dan koin, serta analitik event.

Saya berpartisipasi sebagai frontend developer pada produk web ini. Cakupan produk yang dijelaskan merupakan pekerjaan tim. Studi kasus ini membahas pekerjaan yang saya ikuti, bukan mengklaim kepemilikan pribadi atas setiap fitur. Repository bersifat privat dan tidak mencantumkan identitas commit pribadi saya, sehingga tidak ada tautan kode sumber yang dipublikasikan.

Gambar yang ditampilkan berasal dari landing page tim yang mempromosikan aplikasi mobile. Gambar tersebut menggambarkan konteks produk, bukan tangkapan layar workspace pengelolaan tugas.

## Tanggung jawab saya

- Berpartisipasi dalam pengembangan aplikasi web responsif dengan React, TypeScript, Vite, dan Tailwind CSS.
- Mendukung pekerjaan frontend untuk autentikasi, pengelolaan tugas, pencarian dan filter tenggat, serta pengingat berbasis API.
- Bekerja dalam proyek yang juga mencakup Eisenhower Matrix, profil pengguna, gamifikasi misi dan koin, integrasi API dengan Bearer token, serta analitik event.
- Berkolaborasi dalam alur Agile tim untuk mata kuliah tersebut, bersama pengembangan aplikasi mobile sebagai deliverable terpisah.
